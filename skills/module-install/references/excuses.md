# Module install: excuses

Each quoted sentence below is an excuse for breaking a rule of `../SKILL.md`. Do not accept it;
apply the rule named after the arrow.

## Excuses

- "The CI installs the siblings by hand, so the bare clone must work." → add the bare-clone job
  (default 4).
- "Everybody uses the workspace tool, so the page starts there." → boundary 5.
- "The preset only needs my compiler path." → boundary 2.
- "The version is in the README so it is easy to find." → name the file that holds it.
