# Red flags of a cleanup

Each thought below means stop and go back to the order in `SKILL.md`.

- "It is obviously dead." Show the searches.
- "I will remove it while I am here." Ask first, commit apart.
- "The tests fail, so I will put back the part they need." The item was not unlinked; restore
  all of it and report what reaches it.
- "Leaving it is harmless." It is not; ask about it.
