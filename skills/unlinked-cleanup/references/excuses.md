# Unlinked cleanup: excuses

Each quoted sentence below is an excuse for skipping a step of the order in `../SKILL.md`. Do not
accept it; follow the answer given.

## Excuses

- "It is obviously unused." Show the searches.
- "I will remove it while I am here." Ask first, commit separately.
- "The tests fail, so I will put back the part they need." The item was not unlinked; restore
  all of it and report what references it.
- "Leaving it is harmless." It is not; ask about it.
