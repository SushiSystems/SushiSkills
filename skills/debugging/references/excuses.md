# Debugging: excuses

Read this when a debugging session turns to guessing. The rules are in `../SKILL.md`.

## Excuses

- "It is probably the shader." → measure which stage the value goes wrong in.
- "Could you tell me what the panel shows?" asked five times in a row → add one readout that
  prints everything needed at once.
- "I added a second workaround on top of the first." → find the root cause.
- "The diagnostics might be useful later." → remove them.
