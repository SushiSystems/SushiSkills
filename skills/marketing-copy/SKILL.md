# Marketing Copy

## The ban

Copy with any of these does not ship.

1. **Slogan rhythm.** Three short declaratives, closed adjective triples, imperative stacks.
2. **Jargon as decoration.** A standard or library named for a reader who cannot know what it buys them.
3. **Claims with nothing to picture.** "Real scale", "seamless", "yenilikçi".
4. **The swap test fails.** With a competitor's name in place, the sentence is still true: delete it.
5. **Invented facts or scenes.** A number, customer, benchmark or demo the owner did not supply: write `[number]` and ask.
6. **Superlatives with no comparison.** "Best", "world-class", "en gelişmiş".
7. **Vision standing alone.** Keep it whole, never without a verified fact on the same screen.
8. **Openness as a slogan.** "Anyone can read the code" stands in for a link to the code.

## Instead

1. Build the hero on one true thing a non-specialist can picture.
2. Put evidence beside every large claim: a number with a unit, a date, a video, a link.
3. Give numbers a referent the reader can feel.
4. Name people and dates.
5. Say what is not done ("designed, not yet built").
6. Write for the least technical reader; explain each term once.
7. Name one category first; other work is evidence for it.

## Naming the licence

Name a licence exactly: source-available is described as such, with what it allows and charges for. Never "open source" or "açık kaynak" for a licence that is not one. A closed product that mentions its source is called closed.

## The pass

Read `english.md` or `turkish.md` before drafting. After `humanizer`'s pass, ask of every sentence: can a non-engineer repeat it; does it survive the swap test; would deleting it lose a fact or only a mood; did the owner or a source supply every fact; does a fact sit beside each large claim; would a rival's engineer nod or wince.

Red flags: "needs a punchier closing line"; "a technical term sounds credible"; "a plausible number, they can fix it"; "three short sentences give rhythm"; "the vision is inspiring alone".
